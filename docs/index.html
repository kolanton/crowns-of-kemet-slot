Demonstration build — not a gambling product This is a technical prototype of slot mechanics, not a published game and not a real-money product. It was built as a Unity learning exercise, to practise and show a particular set of techniques: 2D sprite and atlas handling, reel animation and stop timing, weighted random outcomes, payline evaluation with wild substitution and full-column symbols, assembling a game UI from a third-party art pack, and packaging the result as a WebGL build small enough to load on a phone. It uses play-money credits with no monetary value: there is no wagering, no deposit, no purchase and no payout, and credits cannot be bought, redeemed or withdrawn. Outcomes come from an uncertified pseudorandom generator running in your browser, and are deliberately rigged: every fifth spin is forced to pay a large win so the win presentation can be demonstrated on demand. The paytable is illustrative and no return-to-player percentage has been calculated, audited or certified by any gaming authority. Crowns of Kemet

Five-reel, ten-line slot mechanics built in Unity around RetroStyle Games' free Egyptian art pack: weighted reels, wild substitution, a full-column character and ten fixed paylines.
